- `coverage_simulator.py`: 
- `convertJson2Txt.py`: it processes a JSONL file produced by python pytest coverage (e.g., `coverage.jsonl`) and it generates a simplified textual version of such a JSONL file (i.e., `coverage.txt`)
- `extractTrueCrossTests.py`: it processes CSV files generated by means of `coverage_simulator.py` and it filters rows denoting true cross-tests (those where column K is > 0 ). It generates 4 different files: 2 files (i.e., detailed CSV, and simplified TXT) reporting true cross-tests wrt line coverage; 2 files (i.e., detailed CSV, and simplified TXT) reporting true cross-tests wrt branch coverage.
- `computeTestSuites.sh`: it processes CSV files generated by means of `convertJson2Txt.py` and it produces: a random selection of implementation independent test cases in textual format (the size can be configured inside the script); the list of alternative implementations that appears in the input file; for each alternative implementation a random selection of implementation dependent test cases in textual format which correspond to those test in the input file that achieves specified level of line coverage for that specific alternative implementation (the size of the implementation dependent test suite, and the level of line coverage to be used during the filtering can be both configured inside the script)
